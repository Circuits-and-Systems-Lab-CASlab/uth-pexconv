# UTH-pexconv

Converters and tooling bridging the universal format generated by OpenRCX to multiple field solver back-ends (FasterCap, and others planned). Developed as part of the ODE4EC-AMS project.

## Repository structure

```
UTH-pexconv/
├── converters/                 Format converters: universal format to field solver backends
│   └── fastercap/              universal-to-FasterCap converter (in progress, mainly tested on M1oM0 patterns)
├── docs/                       Universal Format documentation
├── examples/                   End-to-end example flows
│   └── fastercap-conversion/   Universal Format to FasterCap conversion, and FasterCap solver run script
├── external/
│   ├── openroad/                OpenROAD (git submodule)
│   └── openroad-patterns/       Wrapper around OpenROAD's gen_solver_patterns,
│                                 using this repo's paths instead of OpenROAD's own
├── .gitignore
├── LICENSE
└── README.md
```
